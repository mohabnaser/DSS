Scenario (II)
• Decision Maker is interested in unknown variables Q(i,j) and T(i,j,k)
• The goal can be expressed as “calculate TPC & TSC corresponding  to 
range of values of variables Q (i,j) and T (i,j,k)”
• So Decision Maker would like to estimate total production and 
shipping cost of alternative values of Q and T.
Compute:
1. Q (i,j) = SUM (k) (T (i,j,k))
2. TPC = SUM (i,j) (U(j) * Q (i,j))
3. TSC = SUM (i,j,k) (S(i,j,k) * T (i,j,k))
Consistency checks
SUM(j)  T(i,j,k) = D(j,k)
Q(i,j) < = C (i,j)
Deterministic Simulation Models
Solved using a simulation language (VDSS, Excel)
